KNR Gold Website - First Version

How to run:
1. Open this folder in VS Code.
2. Open index.html in Chrome.
3. Edit shop text/photos in index.html.
4. Edit colours/design in style.css.
5. Enquiry form currently opens WhatsApp.

Files:
- index.html: website content
- style.css: design
- script.js: menu and WhatsApp enquiry
- images/knr-card.png: visiting card image
